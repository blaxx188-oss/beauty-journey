# Environment Variables Example

This file outlines the environment variables required for the Beauty Journey project. Copy the contents of this file to a `.env.local` file in the root of your project and fill in the appropriate values.

```ini
# ============================================
# Beauty Journey - Environment Variables
# ============================================

# Supabase
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=

# Paymob
PAYMOB_API_KEY=
PAYMOB_HMAC_SECRET=
PAYMOB_INTEGRATION_ID=
PAYMOB_IFRAME_ID=
PAYMOB_MERCHANT_ID=

# Algolia (Future)
NEXT_PUBLIC_ALGOLIA_APP_ID=
NEXT_PUBLIC_ALGOLIA_SEARCH_KEY=
ALGOLIA_ADMIN_KEY=

# Analytics
NEXT_PUBLIC_GA_ID=
NEXT_PUBLIC_SENTRY_DSN=

# App
NEXT_PUBLIC_APP_URL=http://localhost:3000
NEXT_PUBLIC_APP_NAME="Beauty Journey"
NEXT_PUBLIC_APP_LOCALE=ar
NEXT_PUBLIC_CURRENCY=EGP
NEXT_PUBLIC_CURRENCY_SYMBOL="ج.م"

# Email
NEXT_PUBLIC_RESEND_API_KEY=
CONTACT_EMAIL=info@beautyjourney.com
```
